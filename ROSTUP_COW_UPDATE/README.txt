ROSTUP COW FLIGHT — версия только с летающей коровкой

Что изменено:
- Удалены из интерфейса HOUSE DROP / TOWER RUSH и RUNWAY / самолёт.
- Удалены серверные игровые маршруты домиков и самолёта. Оставлены только API коровки.
- Коровка встроена непосредственно в index.html как SVG. Браузеру больше не нужно загружать /static/cow.svg, поэтому ошибка «фото не найдено» для персонажа устранена.
- Оставлен фон космоса static/cow-world.svg.
- Ставка и выигрыш считаются в виртуальных игровых очках. Telegram Stars не списываются и не выплачиваются.

Настройка времени случайного падения:
Файл app.py, строки с COW_CRASH_MIN_SECONDS и COW_CRASH_MAX_SECONDS.
Также можно задать переменные окружения Render:
COW_CRASH_MIN_SECONDS=3
COW_CRASH_MAX_SECONDS=12
Это диапазон времени до случайного падения, а не гарантированный шанс выигрыша. Не выдавайте эти игровые очки за деньги.

Установка:
1. Распакуйте архив.
2. Замените в GitHub файлы app.py, index.html, requirements.txt, render.yaml, .env.example, README.txt и папку static.
3. В static оставьте cow-world.svg. Остальные игровые SVG больше не используются и удалены из архива.
4. Сохраните изменения (Commit changes) и дождитесь Render Deploy.
5. Проверьте https://ВАШ-СЕРВИС.onrender.com/api/health — должно быть {"ok":true,"service":"ROSTUP Cow Flight"}.

Важно: старые таблицы SQLite могут остаться в базе, но игры домиков и самолёта больше не доступны в новой версии. Это безопаснее, чем удалять данные пользователя из базы автоматически.


Обновление: выигрыш показывается крупно на весь экран. Значок ⭐ убран: баланс — виртуальные игровые очки, не Telegram Stars. Ставка: минимум 10, максимум 1000 очков; доступны ×2 и MAX.
